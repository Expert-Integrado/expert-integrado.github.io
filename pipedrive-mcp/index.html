01 · O que é

O CRM sai do clique e entra na conversa.

Um servidor MCP (Model Context Protocol) que roda na sua máquina e dá ao Claude acesso direto — e protegido — à sua conta do Pipedrive.

Você fala, ele faz

"Cria um deal pro cliente X", "quais atividades eu tenho hoje?", "adiciona uma nota no deal 123" — sem abrir o Pipedrive, sem clicar em formulário.

Guardrails de verdade

Antes de criar ou alterar, o MCP verifica duplicatas e campos já preenchidos. Exclusões são bloqueadas na raiz. Nada passa sem confirmação.

IDs viram nomes

Pipeline 5, etapa 42, usuário 17? Você nunca vê isso. As respostas chegam com nome de pipeline, etapa, responsável e opções de campo legíveis.

Qualquer conta Pipedrive

A tool sync_all aprende os campos personalizados, pipelines, etapas, tipos de atividade e usuários da sua conta — e gera um config.js distribuível pro time.

Fuso horário certo

Horários de atividade são convertidos entre o seu fuso (PIPEDRIVE_TIMEZONE) e o UTC da API — a ligação de "amanhã às 14h" cai às 14h.

Resiliente e local

Retry automático em limite de requisições e instabilidade da API, erros explicados em português. O token fica só na sua máquina — nada passa por servidor de terceiros.

02 · Como funciona

Do pedido ao CRM atualizado, com uma checagem no meio.

O MCP roda localmente via npx e conversa com a API oficial do Pipedrive usando o seu token pessoal. Cada etapa abaixo existe no código.

1

Você pede no Claude

Em linguagem natural: "marca uma ligação com o Pedro amanhã às 14h". O Claude escolhe a ferramenta certa entre as 26 disponíveis.

2

O MCP checa os guardrails

Contato já existe? Deal aberto pra essa pessoa? Atividade pendente? Campo já preenchido? Se sim, devolve o conflito em vez de executar.

3

API oficial do Pipedrive

Aprovado, o MCP chama a API v1 com o seu token pessoal, resolvendo nome/alias de pipeline, etapa e responsável para os IDs corretos.

4

CRM atualizado, resposta legível

O registro aparece no funil e o Claude responde com nomes traduzidos e link direto pro item no seu Pipedrive.

Se um guardrail dispara, nada é gravado: a ferramenta devolve o que encontrou (com link pro registro existente) e o Claude pergunta antes de repetir a operação com force: true.

03 · Ferramentas

40 ferramentas, do lead novo ao histórico do deal.

Agrupadas por domínio. As marcadas como preferenciais concentram o fluxo com menos chamadas e mais proteção.

Negócios (deals)

9 tools
  • create_deal_full preferencial pra lead novo: pessoa + organização + deal + atividades em uma chamada, com dedupe
  • get_deal_summary preferencial pra análise: deal + contato + atividades + notas + histórico em uma visão
  • list_deals lista com filtro por status, pipeline e etapa
  • search_deals busca por termo
  • get_deal detalhes com campos personalizados legíveis
  • create_deal cria quando pessoa e organização já existem
  • update_deal status, etapa, valor, responsável
  • update_deal_fields campos personalizados com proteção contra sobrescrita
  • get_deal_flow histórico de movimentações de etapa e status

Contatos (persons)

4 tools
  • search_persons busca por nome, e-mail ou telefone
  • get_person detalhes completos do contato
  • create_person cria com busca anti-duplicata por telefone e e-mail
  • update_person e-mail e telefone são adicionados, nunca substituem

Organizações

3 tools
  • search_organizations busca por nome
  • get_organization detalhes completos
  • create_organization cria com checagem de nome similar

Atividades

4 tools
  • list_activities filtros por tipo, usuário e período
  • list_deal_activities todas as atividades de um negócio
  • create_activity tipos com alias e duração padrão; checa pendências antes
  • update_activity remarcar, concluir, mudar tipo, vincular a deal

Produtos

Notas

Sincronização

1 tool

04 · Guardrails

O diferencial: o MCP desconfia antes de gravar.

CRM sujo custa caro. Cada operação de escrita passa por verificações automáticas — implementadas no código, não só no prompt.

Contato duplicado

create_person busca pelos últimos 8 dígitos do telefone e pelo e-mail, em paralelo, antes de criar. Achou similar? Devolve o link do existente em vez de criar outro.

Deal duplicado

create_deal e create_deal_full verificam se a pessoa já tem negócio aberto. Se tem, listam os deals encontrados e nada é criado sem confirmação.

Atividade duplicada

create_activity confere se o deal ou a pessoa já têm atividade pendente antes de agendar mais uma — adeus follow-ups em dobro.

Organização repetida

create_organization procura organizações com nome similar e mostra o que achou antes de cadastrar uma nova.

Sobrescrita protegida

update_person e update_deal_fields não passam por cima de campo preenchido: devolvem o conflito pra você decidir. E-mail e telefone novos são adicionados, nunca substituem.

Exclusão bloqueada

Nenhuma ferramenta apaga nada — e qualquer requisição DELETE é barrada na camada HTTP do MCP. Protocolo de segurança ativo por padrão.

E quando o aviso é falso alarme? Toda verificação pode ser contornada com force: true — mas o MCP instrui o Claude a usar isso somente após confirmação explícita sua. A decisão final é sempre humana.

05 · Instalação

Cole um prompt no Claude Code. Ele conduz o resto.

O onboarding é assistido: o próprio Claude verifica os pré-requisitos, busca o seu token no painel do Pipedrive por você (via navegador — você só faz o login), registra o MCP e valida com uma chamada real antes de concluir.

1

Copie o prompt do README

Um único bloco de texto, pronto pra colar no Claude Code. Ele confere Node.js 18+ e o que mais for necessário.

2

O Claude busca seu token

Na etapa do navegador ele pergunta: "quer que eu faça pra você?". Se sim, abre o painel do Pipedrive (Configurações → Preferências pessoais → API), você faz o login e ele copia o token da tela. Sua senha nunca passa pelo chat.

3

Registro + validação real

Ele registra o MCP com as variáveis certas e testa o token com uma chamada de verdade à API (listar um deal) antes de declarar pronto. Depois é só reiniciar o Claude Code.


# Com o token em mãos, o registro é um comando:
claude mcp add pipedrive -s user \
  -e PIPEDRIVE_API_KEY=SEU_TOKEN \
  -e PIPEDRIVE_TIMEZONE=America/Sao_Paulo \
  -- npx -y @expertintegrado/pipedrive-mcp

Prompt completo de instalação assistida no README. Rota 100% manual (Claude Desktop, ZIP, git clone, ambientes offline) no INSTALL.md.
