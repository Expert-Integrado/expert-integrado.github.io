01 · Como funciona

Do pedido em português até o seu Zoom, sem intermediário

O servidor roda na sua máquina e fala direto com a API oficial do Zoom. Nada passa por servidores da Expert Integrado.

1

Você pede no Claude Code

Em português, do seu jeito: "quem são os membros do canal #vendas?", "mostra as últimas mensagens do #geral".

2

O Claude escolhe a tool

Entre as 20 tools do servidor — por exemplo, zoom_start_thread pra abrir um assunto ou zoom_list_channels pra listar canais.

3

O servidor local autentica

O Zoom MCP roda na sua máquina (via npx), lê o token OAuth salvo em tokens.json e o renova automaticamente quando expira.

4

Chamada à API oficial do Zoom

Requisição HTTPS para api.zoom.us/v2, com retry exponencial em erros temporários e paginação automática em listas grandes.

5

O resultado volta no chat

Resposta formatada em português — canal criado, mensagem enviada, lista de membros — pronta pra você conferir e continuar a conversa.

03 · Instalação guiada

Cole um prompt no Claude Code e ele conduz tudo

Inclusive criando o app no Zoom Marketplace por você, pelo navegador — você só faz o login. Sem editar arquivo, sem mexer em JSON.

1

Instale os pré-requisitos

Node.js 18+ e Claude Code, uma vez só. O próprio prompt verifica se está tudo no lugar antes de começar.

2

Cole o prompt do README

A cada etapa que acontece no navegador, o Claude pergunta: "quer que eu faça pra você?". Se sim, ele opera o navegador (Playwright MCP, ou a extensão Claude in Chrome se você já usa), narrando cada clique — e você só entra com o seu login. Prefere manual? Ele orienta um passo por vez.

3

Ele cria o app, registra e testa

Cria o app (tipo "General App") no marketplace.zoom.us com os escopos de Team Chat, registra o MCP no Claude Code, valida as credenciais com uma chamada real à API na autorização OAuth e fecha com um teste de ponta a ponta listando os seus canais.

Suas credenciais ficam com você. O Client ID e o Client Secret vão direto pro comando de registro (nunca são repetidos no chat), e os tokens de acesso ficam num arquivo local (tokens.json), fora do controle de versão. Cada pessoa cria o próprio app na própria conta Zoom.

04 · Segurança

Local por padrão

Tokens só na sua máquina

A autorização OAuth grava os tokens em tokens.json, local e fora do git. A renovação é automática — você autoriza uma vez.

Nenhum intermediário

O servidor roda localmente e conversa direto com a API do Zoom. Nenhuma credencial ou mensagem passa por servidores da Expert Integrado.

Escopos mínimos

O app pede só permissões de Team Chat (e a leitura do seu próprio usuário). Cada pessoa cria o próprio app, na própria conta.
